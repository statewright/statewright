# Statewright 0.3.0 Release Cut

Status: candidate artifacts prepared; pending validation and local release commit.

This release promotes transparent managed model routing for the two hosts whose
process-boundary behavior is implemented and tested:

- Codex restarts the same thread at an authoritative Statewright boundary with
  the new state's model and reasoning effort.
- Claude Code forks the saved conversation at an authoritative boundary with
  the new state's model. Claude has no documented CLI reasoning-effort flag,
  so effort is recorded as advisory.

Both managed clients use a supervisor-owned immutable client identity and an
authenticated loopback MCP bridge. Route requests are explicit `*.route.json`
artifacts and include the identity that the supervisor validates. A route
boundary is a process restart, not an in-turn model hot swap. The user-facing
proof is the resumed-session record showing the prior and selected model.

Pi, OpenCode, and Cursor remain on the `0.2.0` release line until their own
live-routing validation is complete. Oh My Codex remains on its existing
`0.1.x` line. This release does not claim parity for those hosts.

Required gates are the plugin contract suite, generated-bundle drift checks,
shell syntax, a same-thread Codex canary, and a forked-session Claude canary.
Rollback is the prior plugin commit plus disabling managed routing in
`~/.statewright/config.json`; ordinary unmanaged CLI invocation remains
available.
