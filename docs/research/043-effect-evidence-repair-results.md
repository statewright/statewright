## Implemented boundary

- Code-owned AST component envelopes retain source spans, effect bounds,
  completeness, location, capability and provenance. Composition does not erase
  unknown executable nodes, nested substitutions or file redirects. Complete
  read evidence can recover syntax-only opacity without lowering known-risk
  floors. This is an initial strict read/composition adapter, not general
  semantic coverage for every non-read command.
- Shared structural redirect handling distinguishes descriptor duplication,
  literal null sinks and actual file writes. Existing owned pending redirect
  work is included as the prerequisite recorded in report042; unrelated
  canonical/index/worktree changes are not imported.
- A generic literal option binder preserves flag/value roles, clusters, attached
  values and the end-of-options boundary. The rsync semantic adapter uses that
  contract in both ordinary and redirected paths. Unknown flags, abbreviations,
  remote launchers and nonliteral argv cannot manufacture a local-write proof.
- Shared tokenization preserves empty quoted arguments and quoted numeric
  operands next to redirects. Parameter/substitution and unquoted pathname-glob
  expansion retain uncertainty instead of pretending source spelling is argv.

Independent read-only review found unsupported AST fallthrough, attached remote
launcher arguments, redirected-adapter bypass and empty-argument loss. Each was
repaired with regressions; the reviewer found no remaining must-fix in those
repaired paths. This is not an independent security audit of the whole classifier.
