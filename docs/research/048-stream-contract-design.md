# Bounded stream utility contracts

Source-only implementation, 2026-11-09. No corpus commands, Cargo suites,
prototype programs, help acquisition, model requests or installations were run
by this worker. Main integration owns compiled verification and the frozen
corpus replay; no automatic-passage improvement is claimed here.

The native Bash AST still unions every child, redirect, expansion and unsupported
context. These contracts extend only missing leaf evidence, after rejecting
assignment context and truncated evidence. No probability, threshold, risk floor,
capability rule, legacy classifier or fixture label changes.

Bare trusted GNU/POSIX grep aliases, tac, expand, unexpand, fmt and pr receive an
argument-invariant Read ceiling. Their operands and patterns are data; no option
delegates an arbitrary program or writes a named output. This retains the existing
standard-utility identity assumption, not proof of the actual resolved binary.

Sort and diff require complete literal argv and a closed option-role parser.
Unknown options and missing required values reject the contract. Values consumed
by a known option are data, and `--` ends option processing. Sort rejects helper
options such as `--compress-program`; its ceiling includes Read and Write because
sorting can create temporary files or named output. Diff rejects `-l` and
`--paginate`, which can delegate pagination. Format strings are output data.

Sed requires literal options and script fragments from a bounded grammar. The
grammar supports numeric, dollar and delimited regex addresses, negation,
stream-only commands, labels/branches, substitution and transliteration. Each
fragment must parse completely, without newline/control continuations, comments,
brace blocks, script files, in-place options, file commands or execution commands.
Substitution flags admit only print/global/numeric selection; `e` and `w` reject.
Unescaped bracket expressions reject because their delimiter lexical rules vary.
Deletion of pattern-space lines has a Read ceiling and does not become resource
Destroy. In-place edits still use the existing classifier path, not this contract.

Awk program grammars, file-loaded scripts, dynamic sort/sed/diff arguments,
unsupported sed syntax, arbitrary executable paths, configured helpers and source
binding remain unresolved. A complete general interpreter parser is outside this
bounded slice.

Focused selectors for integration: `stream_options_bind_data`,
`sed_bounds_program_grammar`, and `bounded_stream_contracts_compose`.
