## Decision

Managed hooks use the configured loopback bridge and its token with no direct
gateway fallback. An incomplete/non-loopback bridge fails closed. Hook call
timeout stays within its host hook deadline.

Desktop binds a workflow service, persistent origin store, route-owner identity
and local telemetry writer per lane. The shared route proxy responds only to
successful local lifecycle completions correlated to the current native turn.
It checks authoritative run/session/state/epoch, interrupts the owning old turn,
waits for idle, confirms native settings and starts a new native turn. Display
summarization is not an execution authority: lifecycle handling uses the
original structured tool event before its display-only summary.

Manual user activity invalidates pending handoffs. If cancellation occurs while
the internal start RPC is outstanding, its exact returned continuation is
interrupted without overwriting newer user ownership. Approval-pending states
remain parked; this patch does not approve them or repair their separate UI.
No prompt-instruction-only switching, new shared daemon, gateway modification,
silent model fallback or blanket unknown-RPC exception.
