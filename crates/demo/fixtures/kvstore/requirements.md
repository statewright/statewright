# Key-Value Store

Build a Python key-value store class called `KVStore` in `kvstore.py`.

## Requirements

1. `set(key, value)` — store a value by key, overwrite if exists
2. `get(key)` — return the value for a key, return None if missing
3. `delete(key)` — remove a key, return True if existed, False if not
4. `exists(key)` — return True if key exists, False otherwise
5. `keys()` — return a list of all keys
6. `size()` — return the number of stored items
7. `clear()` — remove all items
