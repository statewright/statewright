# statewright-agent

LLM agent coordinator that uses state machine guardrails to structure multi-step tasks. The agent layer sits between the LLM and the engine, managing tool schemas, transition decisions, and execution flow.

Used by the TUI demo and the MCP gateway.

Apache 2.0.
